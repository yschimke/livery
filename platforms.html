Kotlin#

  • HTTP through Ktor: OkHttp on Android and the JVM, Darwin on iOS, fetch on Wasm.
  • JavaCrypto (JVM, Android 13+) verifies Ed25519; on older Android or other targets pass your own Crypto.
  • Android modules compile against SDK 37.1.

Compose Multiplatform#

LiveryTemplate(plan, host) plays a render plan through rc-players' Compose player; LiverySlot(key, host) { plan } plans and falls back, replanning when key changes or the repository's revision does (a refreshed catalog, an install). Catalog images and fonts go through the player's own loaders.

Swift#

A native SwiftPM package with no dependencies beyond the system: URLSession, CryptoKit, SwiftUI. LiverySlotView takes any player view. For rc-players' native Swift player, add swift/Integrations/RcNativePlayer/LiveryRcNativePlayer.swift to your app beside your own RcNativePlayerUIKit dependency.

LiverySlotView(key: decision.decisionId, actions: router, events: analytics,
  plan: { await planner.forDecision(query, decision) },
  player: { LiveryRcNativePlayer(input: $0) },
  fallback: { _ in NativeBanner() })

Conformance#

Kotlin and Swift run the same fixtures in conformance/: selection, binding, resources and signing must give identical answers on every platform.
