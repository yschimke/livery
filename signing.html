Signing#

Every production manifest is signed. A compromised host or CDN can't push designs, hide a revocation or roll a catalog back.

Keys#

livery keygen acme          # acme.key (secret), acme.pub (embed in apps)
  • acme.key is PKCS#8 in Base64. Keep it in CI secrets; never commit it.
  • acme.pub is the raw 32-byte Ed25519 public key in Base64. Apps embed it with a key id.
TrustPolicy.Signed(listOf(TrustedKey("acme-1", ACME_PUB.decodeBase64()!!)))  // okio: the key is a ByteString

.signed([TrustedKey(keyId: "acme-1", publicKey: Data(base64Encoded: acmePub)!)])

Sign and verify#

livery build catalog out --key acme.key --key-id acme-1
livery verify out --pub acme.pub --key-id acme-1

The signature (manifest.sig.json) is Ed25519 over the exact bytes of manifest.json. Never re-encode or reformat the manifest after signing; serve it byte for byte.

Partner keys#

A key can be limited to contract prefixes. An ad partner's key that may sign only ads/:

TrustedKey("adnet-1", adnetPub, contractPrefixes = setOf("ads/"))

A manifest signed by that key that mentions any other contract is rejected.

Signing one document#

A document sent with a message instead of through a catalog (an A2UI template) carries its own signature, by the same keys and held to the same contract prefixes (PROTOCOL.md §3.4):

livery sign-template designs/banner-classic/in-app.rc --contract promo/banner@1 --key acme.key --key-id acme-1

It prints the template JSON to send, {"inline": <base64>, "signature": {...}}. The client still checks the document against its contract, and plays a signed one only if it uses no risky feature (shaders, haptics, sound, particles, embedded images or fonts, wake) that the app hasn't opted into. An unsigned document plays only under the app's unsigned-document policy, and never with a risky feature (PROTOCOL.md §3.5).

Catalog templates are held to the same features. livery build records the ones a document uses in its manifest entry (features, and the catalog then needs protocol level 8), and selection skips a template whose features the player doesn't allow, PlayerCapabilities.features, empty by default, so a shader design draws only where an app opted into shaders.

Rotation#

Ship the new public key in an app release alongside the old one, then sign with the new key once enough installs have it. Remove the old key from a later release.

Freshness and the kill switch#

  • serial must grow per channel; a lower one is refused (rollback protection).
  • After expiresAt (default 14 days after the build) the catalog is stale but still played for a grace period; then apps stop using it.
  • revoked: true on a design or template withdraws it at the next refresh; minClient keeps a catalog away from apps too old for it.

TrustPolicy.AllowUnsigned exists for development and preview channels only.
